# Audio Visualizer

A single-file, phone-friendly music visualizer. Load a song, pick a style, and export a video.

**Live page:** https://beardedgoat824.github.io/vids/

## Features
- Bars, circle, mirror and lyric styles, with themes and fonts
- Reads timed lyrics straight out of an M4A file, or paste your own in the lyric editor
- 11 lyric animations (fade, slide, rolodex roll, flip, flash, pop, word pop, typewriter, glitch, wave) with a speed slider
- Fast MP4 export (faster than real time) using WebCodecs, or real-time recording as a fallback
- Keeps the screen awake while exporting
- Works on phones; everything runs in your browser, nothing is uploaded

## Use it
Open the live page, or download `index.html` and open it in Chrome. No install needed.
